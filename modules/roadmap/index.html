LaunchPad product roadmap

Where LaunchPad is headed

Best saved as A4 landscape - choose landscape in the print dialog if it is not preselected.

One work set, read at the altitude you need. Workstreams is the strategic gantt of high-level containers for the C-suite; Categories rolls work up by theme; Work Items shows it item by item; Backlog is the full prioritised list, active through far-future parked. Use the Department filter to narrow any of them. Every item is a row in the work_items table in Supabase and is edited there (see docs/ROADMAP.md); this page renders live table state.
