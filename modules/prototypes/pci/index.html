PCI Compliance - IXOPAY integration (confirmed model)

One API enrolment call with our existing merchant payload; IXOPAY pre-fills the SAQ, invites the merchant by email, chases them, and runs the annual lifecycle forever; Launchpad adds the fee product on invitation-sent and monitors status via webhook + 15-30 day polling.

In build Owner: Product (onboarding)

Overview

Launchpad captures merchant data exactly as today. At the compliance prompt, a merchant claiming existing compliance is verified via IXOPAY's records; otherwise a single API call enrols them, sending the full data already collected. IXOPAY derives and pre-fills the SAQ, emails the merchant an invitation link, guides a deliberately easy, non-technical completion, chases anyone who stalls, and runs the annual revalidation cycle forever. Launchpad's role is deliberately thin: on the invitation-sent event it adds the fee product to the basket, then monitors status via a webhook backed by 15-30 day polling and pulls reporting on demand.

Purpose

Stress-free, automated compliance with near-zero Launchpad build; replaces the un-scoped VikingCloud integration gap.

Benefits

  • Enrolment-focused API, no data re-capture.
  • Merchant not required live.
  • IXOPAY owns chasing and perpetual revalidation.
  • Fee pass-through automated via the basket product.
  • Reporting API for totals and granular data.
  • Records retained permanently by IXOPAY.
  • Consolidation path for website screening, GDPR, PEPs & sanctions.

Features

  • Faithful PXP Partner Portal wizard: application, operating sites, products and pricing.
  • PCI compliance interstitial on proceed - a light-touch hold-up with a skip failsafe.
  • Confirm-compliant path (optional status check and managed engagement) or full enrolment.
  • Full-payload enrolment with a data review, then an enrolment email - no re-capture.
  • Highlighted PCI Compliance Fee added to the Quote Tool basket on invitation sent.
  • Webhook and 15-30 day polling monitor.
  • Compliance reports: engagement, status, webhooks outstanding, chases.
